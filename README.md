# RCA_CIE2_Activity1_AD3157
# Activity 1: Multiple Linear Regression

## 1. Project Title
**House Price Prediction using Multiple Linear Regression**

## 2. Project Description
The objective of this project is to predict house prices using Multiple Linear Regression.

The model uses different numerical features such as median income, house age, average rooms, population and geographical location to estimate the median house value in California.

This project demonstrates data preprocessing, exploratory data analysis, manual calculation of regression coefficients, model building, evaluation and prediction.

## 3. Dataset Information
- **Dataset Name:** California Housing Dataset
- **Dataset Source:** Scikit-learn
- **Total Records:** 20,640
- **Total Columns:** 9
- **Target Variable:** MedHouseVal

**Dataset Features:**
1. MedInc – Median income
2. HouseAge – Average house age
3. AveRooms – Average number of rooms
4. AveBedrms – Average number of bedrooms
5. Population – Population of the area
6. AveOccup – Average house occupancy
7. Latitude – Geographical latitude
8. Longitude – Geographical longitude

**Dataset Source:** https://scikit-learn.org/stable/datasets/real_world.html#california-housing-dataset

## 4. Work Completed
- Loaded the California Housing dataset using Python.
- Performed data inspection and preprocessing.
- Checked missing values and duplicate records.
- Performed Exploratory Data Analysis (EDA).
- Created scatter plots to understand relationships between features and house prices.
- Generated a correlation heatmap.
- Manually calculated regression coefficients using the Normal Equation.
- Implemented Simple Linear Regression.
- Implemented Multiple Linear Regression.
- Divided the dataset into 80% training data and 20% testing data.
- Evaluated model performance using regression metrics.
- Analysed residual plots and prediction errors.
- Checked multicollinearity using Variance Inflation Factor (VIF).
- Predicted the house value for a new example.

## 5. Model Evaluation Results

The model was evaluated using the following performance metrics:

MAE: 0.5332001304956551
MSE: 0.555891598695244
RMSE: 0.7455813830127761
R2 Score: 0.5757877060324511

## 6. Conclusion
In this project, Multiple Linear Regression was implemented to predict California house values using multiple numerical features.

Exploratory Data Analysis helped understand the relationship between different features and the target variable. The model was evaluated using MAE, MSE, RMSE and R² score to measure its prediction performance.

The project provided practical experience in data preprocessing, regression modelling, model evaluation and interpreting predictions.
